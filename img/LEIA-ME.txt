FOTOS DO SITE
=============

Para trocar uma foto, envie outra com EXATAMENTE o mesmo nome para esta pasta (img).
Se uma foto não existir, o site mostra um bloco cinza com a descrição (sem quebrar o layout).

logo-haus.png                     Logo com fundo transparente (cabeçalho, gerador e PDF).
                                  Refeita a partir de uma imagem pequena: trocar pelo arquivo original quando tiver.
logo-haus-claro.png               A mesma logo em tom claro, para o rodapé escuro
favicon-64.png / favicon-180.png  Ícone da aba do navegador e do celular
og-image.jpg                      Imagem que aparece ao compartilhar o link (1200 x 630)
hero.jpg                          Foto do topo (quadrada, 1100 x 1100)
sobre.jpg                         Foto da proprietária ("Novo espaço, a mesma essência"); enviar em alta se tiver

de banco de imagens do Unsplash (unsplash.com, licença livre para uso comercial, sem crédito
obrigatório). Troque pelas fotos reais da Haus assim que tiver.

Dicas:
- Use fotos .jpg com até ~300 KB cada (dá para reduzir em squoosh.app ou tinypng.com).
- Ao trocar uma foto de projeto, atualize no index.html o texto "alt" dela,
  descrevendo o ambiente (ajuda no Google).
